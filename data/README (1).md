# Data directory

This directory is reserved for **generated and validated analysis outputs** from the review-collection notebook.

## How to generate the data

1. Open `../notebooks/MoveInSync_Low_Rating_Reviews_Collector.ipynb` in Google Colab.
2. Run all cells.
3. Download the CSV output and its matching metadata JSON.
4. Before placing them here, verify the actual row count, 1–2 star ratings, date range, duplicates, and source references.
5. Keep the metadata JSON next to the CSV so the collection run can be traced.

## Expected outputs

The collector aims for up to 500 unique, written 1–2 star reviews from the newest accessible source frame. It may produce either:

- `MoveInSync_500_Low_Rating_Reviews.csv` if 500 eligible records are available; or
- `MoveInSync_Low_Rating_Candidates_NOT_500.csv` if fewer than 500 are available.

It also writes `MoveInSync_500_Low_Rating_Reviews_metadata.json` with collection metadata. The filenames are generated by the collector; use the actual filename produced by your run.

## Important

- **Do not create a placeholder CSV or claim 500 records unless the file actually contains 500 valid records.**
- The collected records are a sample from the newest accessible reviews, not a representative sample of all historical reviews or all app users.
- Monthly counts are review counts, not complaint rates per trip or user.
- Rule-based issue tags are provisional and need manual quality checks.
- The collector omits reviewer names/profile URLs and full review text from its CSV output.
- Do not commit credentials, personal data, or any data you are not authorized to share.

If no dataset has been generated and validated yet, leave this directory with this README only.
